Block text

Paragraph

Capy abstracts away sockets, files, and asynchrony with type-erased streams and buffer sequences—code compiles fast because the implementation is hidden.

Boost.Charconv converts character buffers to numbers, and numbers to character buffers. It is a small library of two overloaded functions designed for performance and consistency across supported development environments.

Paragraph — with inline link

See the Capy overview for the design rationale, and the streams section for API details.

See the section on conversions for details, and the cppreference page for to_chars for the standard reference.

Paragraph — with inline code

Read from an any_stream with read_some(mutable_buffer) and write back with write(stream, const_buffer).

Call boost::charconv::to_chars with a buffer range and a numeric value. The result holds a ptr and an ec field.

Paragraph — with strong

Streams are type-erased, buffer-friendly, and coroutine-aware.

The library is locale-independent, non-allocating, and non-throwing.

Paragraph — with em

I/O is composable across socket, file, and in-memory back-ends.

Conversions are round-trip safe for all finite IEEE-754 values.

Paragraph — with sup/sub footnote

An any_stream is one-shot1. The internal buffer index is base-22.

Charconv is non-allocating1. The exponent uses base 1010 internally.

Paragraph — with kbd keyboard key

Press Ctrl+C to cancel an in-flight read_some.

Press Ctrl+C to copy the buffer contents.

Footnote entry (bottom-of-page)
1. A stream is exhausted after read_some returns eof; create a new any_stream to reuse the back-end.
1. The one edge case where allocation may occur is when parsing a string to an 80- or 128-bit long double.

Code Example 1. Echo over a stream
task<> echo(any_stream& stream) {
    char buf[1024];
    auto [ec, n] = co_await stream.read_some(mutable_buffer(buf));
    auto [wec, wn] = co_await write(stream, const_buffer(buf, n));
}
Code Example 1. Serialize an integer
#include <boost/charconv.hpp>

char buf[16];
auto r = boost::charconv::to_chars(buf, buf + 16, 42);
if (r.ec == std::errc()) {
    // success
}
